# Pacific Data Viz Challenge 2026 

## How to Run Streamlit App (for Team Members)
See https://www.datacamp.com/tutorial/streamlit for general guidance. 
Steps (If you have Windows):
1. Install Anaconda Navigator and Distribution here https://www.anaconda.com/download
2. Create new environment in Anaconda Navigator to run on your desktop.
3. Make sure to install the relevant Python packages. At the moment this will be streamlit and sdmxthon
4. run the command ' streamlit run  https://raw.githubusercontent.com/klaragerlei/data_viz_challenge_26/refs/heads/main/visualise2.py '
